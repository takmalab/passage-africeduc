# Démo technique (6 min maximum)

Enregistrement d'écran commenté, sans montage : on doit voir le produit tourner. Les 7 scénarios de la section 3.4 du sujet sont montrés **explicitement**, dans l'ordre du sujet. Matériel : le PC (navigateur du responsable, simulateur de badges) et le téléphone Android (application installée, compte agent).

## Préparation (hors caméra, 15 min)

1. `npm run db:seed` puis `npm start` (le PC sert `https://<ip-du-pc>:8443`, certificat mkcert installé sur le téléphone).
2. **Délai de grâce à zéro** (scénario 4) : dans le `.env`, `WINDOW_GRACE_MINUTES=0`, puis redémarrer `npm start`.
3. **Jour et heure du tournage.** L'itinéraire de démonstration ne s'applique que du lundi au vendredi ; un scan un autre jour donne l'anomalie « point imprévu ». Dans **Paramètres, Itinéraire de l'établissement**, **régler d'abord les plages, puis cocher le jour** (une plage déjà passée, cochée pour aujourd'hui, crée aussitôt une alerte par élève) :
   - **Portail entrée** : de maintenant à maintenant + 2 h (couvre tout le tournage) ; cocher le jour ;
   - **Portail sortie** : de maintenant + 5 min à l'heure prévue pour la scène 4 + 3 min (le programme de fond passe chaque minute) ; cocher le jour ;
   - **Bus** : ne pas cocher le jour (pas de bus ce jour-là).
4. Téléphone : application ouverte, compte agent, point « Portail entrée », mode QR. PC : responsable connecté, onglet **Simulateur de carte** ; un second onglet en navigation privée avec le compte `parent.awa`.
5. Noter l'identifiant de Kevin (fiche élève du responsable, dans l'adresse) pour le scénario 6.
6. Terminal prêt avec `npm test -w apps/api -- sync.int` (scénarios 1 et 2).

## Après le tournage

- Remettre la clé `AI_API_KEY` et `WINDOW_GRACE_MINUTES=15` dans le `.env`, l'heure automatique sur le téléphone.
- `npm run db:seed` pour revenir aux données de démonstration.
- Vérifier que la vidéo dure **6 minutes au plus**, puis la mettre en ligne (YouTube non répertoriée) et tester le lien en navigation privée.
