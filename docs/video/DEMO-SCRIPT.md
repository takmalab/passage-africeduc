# Démo technique (6 min maximum)

Local, sans connexion Internet. Écran partagé : navigateur responsable à gauche, téléphone agent (ou fenêtre mobile) à droite. Avant : `npm run db:seed`, `npm run build`, `npm start`.

| Temps | Scène (exigence 3.4)           | À montrer                                                                                                                            | À dire                                                                                        |
| ----- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| 0:00  | Introduction                   | Page de connexion                                                                                                                    | « Passage : suivi des passages par carte NFC, hors ligne, avec synthèse IA sous garde-fous. » |
| 0:20  | 1. Scan sans réseau            | Agent : mode avion, simulateur « Poser la carte » 20 fois (ou script), compteur « 20 en attente »                                    | « Chaque scan est d'abord gardé dans le téléphone. »                                          |
| 1:10  | 1 suite                        | Réseau rétabli : envoi automatique ; responsable : 20 passages                                                                       | « Exactement 20. » Montrer aussi `npm test` : test « 20 scans » vert.                         |
| 1:40  | 2. Synchronisation interrompue | Couper pendant l'envoi, relancer ; toujours 20 ; montrer le test « interrompue puis reprise »                                        | « Le serveur reconnaît ce qu'il a déjà : aucun doublon. »                                     |
| 2:20  | 3. Badge photographié          | Simulateur : QR affiché, scanner (accepté) ; photographier avec un autre téléphone, présenter : refusé                               | « Code déjà utilisé : copie probable. Le parent est prévenu. »                                |
| 3:10  | 4. Élève qui ne passe pas      | Fiche élève : fenêtre qui se termine dans 1 min (`WINDOW_GRACE_MINUTES=0`), ne rien faire, attendre, anomalie + message apparaissent | « Personne n'a ouvert l'application : le programme de fond l'a détecté. »                     |
| 4:00  | 5. Horloge fausse              | Téléphone à +2 h, scanner, liste des passages : « Horloge corrigée », bonne heure                                                    | « Le décalage est mesuré à l'envoi et corrigé. »                                              |
| 4:40  | 6. Parent curieux              | Parent A, changer l'identifiant dans l'URL : « Élève introuvable »                                                                   | « Le filtre est dans la requête ; même réponse qu'un élève inexistant. »                      |
| 5:15  | 7. Synthèse sans clé           | Sans `MISTRAL_API_KEY`, générer : phrase « Gabarit », chiffres exacts                                                                | « Le modèle ne compte jamais ; sans lui, le gabarit donne les mêmes chiffres. »               |
| 5:45  | Fin                            | Onglet GitHub Actions vert                                                                                                           | « Code, tests et décisions dans le dépôt. »                                                   |
